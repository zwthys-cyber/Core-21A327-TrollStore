## 本轮修改

1. 采集完成即释放目标／缓存互斥锁，后续使用已保留的网格和姿态快照。CPU 蒙皮、栅格及遮挡查询不再继续占用采集所需的锁；绘制另用独立互斥锁，重叠的绘制回调直接跳过，不排队提交陈旧帧。
2. 先完成世界坐标蒙皮，再重新取样相机及屏幕尺寸，用这份更新的相机统一完成投影、原生校验和射线重建。减少相机取样后等待采集／蒙皮的时间，不使用上帧颜色或旧屏幕坐标。
3. 大三角形按保守扫描行区间减少外部候选像素；实际覆盖和深度仍由原来的逐像素浮点公式计算。病态／小三角形回退到原包围盒扫描。新增 8,000 组与旧算法的逐字节覆盖、深度、覆盖位及重叠比较。
4. 状态增加采集锁等待、后置相机取样次数、投影耗时、相机取样到提交填色的时间及重叠绘制计数，供手机复核。

## 验证与限制

编译、自动化测试及签名／载荷检查只在 GitHub Actions 执行。生产入口测试覆盖移动后的最新相机、投影及两种查询路径不持采集锁、重复回调不排队，以及原有红白颜色、查询失败、LOD、缓存、退出路径和 ABI。

新增版本为 `CoreModelRenderVersion=11`、Bundle build `39`，安装包 `Core-17.0-21A327-TrollStore-model-render-v11.ipa`。这是一轮有针对性的时序和栅格优化，尚无 v11 手机耗时数据，不能承诺已经消除所有闪烁、错位或卡顿。逐像素场景查询仍有 12 ms 预算；未完成的整帧仍跳过，保留真正错误／未就绪时的拒绝行为。
