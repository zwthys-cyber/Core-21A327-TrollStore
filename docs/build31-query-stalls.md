## build 32 改动

- 栅格化在首个有效表面写入时设置覆盖位，每像素一位；最近表面覆盖不会重复计数。查询、分类收尾和矩形打包跳过空白位，仍保持每个覆盖像素、同一深度及颜色判断。原全分辨率深度缓冲继续存在。
- 同一覆盖像素的射线方向和距离每帧只计算一次，在三个场景间复用。临时射线存储最多 8 MiB，超过上限改为按需计算；不会分配与整个大遮罩成正比的巨大射线数组。原 12 ms 查询预算、原包装函数比较/回退及 96 字节 ABI 保留。
- 元数据发现保存 LOD 描述及参考骨骼，静态顶点/权重/索引缓冲改为通过当前可见性与 LOD 筛选后才载入。隐藏的主组件仍提供附件动画所需的骨骼身份、逆绑定和当前姿态，不必先载入其三角形。
- 目标切换 LOD 时按需载入并保留当前选用项，其余项可由原有 LRU 淘汰。同一实际静态资源在不同人物的不同附件槽位出现时共享缓存；元数据绑定校验仍核对槽位。
- 报告分别记录模型/读取、栅格与遮罩分配、查询与射线准备、矩形打包、原生提交耗时，并新增覆盖量、临时射线内存及网格载入不可用计数。模型阶段包含元数据时间，比较总计时不要重复相加。
