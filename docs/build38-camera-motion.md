# 人物填色 v10 / build 38：移动视角时的投影误拒绝

用户在填色 v9 / build 37 反馈：自己移动或转动视角时，人物填色闪烁。

## 确认的代码问题

`CMLDraw` 开始时复制 52 字节相机数据，`CMPMakeView`、人物网格投影及像素射线重建使用该副本。v9 的原生投影校验却直接读取 `context+0x1F4` 的实时相机。采集网格、姿态及 CPU 蒙皮期间，上游可能更新该相机；两次投影使用不同的相机时会超过原有 0.75 像素阈值，导致整个网格在本帧被跳过。被遮挡部分的红色也会随整块填色消失。

v10 只将原生投影校验的相机参数改为本帧已经捕获的副本，所有投影、校验及像素射线使用相同相机。保持原校验阈值、600 米范围、逐像素遮挡查询和可见白色／遮挡红色规则。没有沿用上帧填色，也没有将未完成的查询当作无遮挡。

## 回归和验证边界

生产入口回归在相机快照完成后、读取网格状态时更新实时相机，覆盖三个平移轴、俯仰／偏航／翻滚及视场角变化，每种连续六帧。期望每帧仍提交红白填色，不增加投影不符计数。另保留真正错误的原生投影仍跳过网格的检查。

仅新增回归、尚未修改 v9 生产代码时，[Actions 39147118666](https://github.com/zwthys-cyber/Core-21A327-TrollStore/actions/runs/39147118666) 在移动相机后应继续填充的断言失败，复现了该代码问题。首次增加 UBSan 也指出模拟读取器中的地址减法需要先计算偏移；测试读取器已加括号，避免先构造越界指针。

回归及编译只在 GitHub Actions 执行，包括 ASan/UBSan 生产渲染测试、现有采集、蒙皮、像素／射线和签名／完整载荷核验。本机只编辑文件及检查版本与摘要。

版本识别：`CoreModelRenderVersion=10`、Bundle build `38`；安装包 `Core-17.0-21A327-TrollStore-model-render-v10.ipa`。状态新增 `projection_camera_snapshot=true`。

该修复针对相机跨时刻校验导致的网格消失，尚须用户手机确认。查询时间或矩形数量不足、目标状态读取失败、几何未就绪、实际 LOD 及其他精度问题仍可能造成缺绘；`full_requested_effect_verified` 保持 false。
