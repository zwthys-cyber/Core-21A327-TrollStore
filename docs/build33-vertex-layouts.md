## build 34 改动

- 载入与蒙皮支持实机观察到的 24、28、32 字节步长，每条顶点按自身步长寻址，位置仍在 +8。只支持这些已观察布局，不任意接受所有步长。
- 对新增 28/32 字节布局，要求全部位置通过有限数值及资源边界检查；继续保留权重总和、索引范围、分区和骨骼表校验。失败计入新增 `position_shape`，不会用错误步长勉强绘制。
- 在线状态报告记录各步长的实际载入次数及支持列表。离线预览使用同样的步长和新增布局边界校验，避免将新增头部继续排除在预览外。
- 实时组件状态根据已发现的反射字段计算所需前缀，覆盖对象头、附件图、变换、网格身份、姿态、主骨骼映射、可见性及 LOD。当前实机字段所需范围约 2.4 KiB；字段尚未发现时仍回退至原完整前缀，高偏移字段会扩大读取。
- 每秒元数据复用的根组件读取只需固定 `0x830` 前缀，覆盖其实际使用的附件数组与资源指针。报告新增组件状态读取次数、字节与最大前缀，以实测下一轮是否减少 gather 开销。
