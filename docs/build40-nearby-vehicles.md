# 附近载具 · render v12 / build 40

基于人物红白填色 v11（`cf70799`），在原“位置”页面增加独立的“附近载具”开关。显示已识别、投影有效且距离在 0～600 米（含边界）的载具名称和距离，使用黄色黑描边文字，字号随原界面缩放。人物标记及全分辨率红白填色继续使用 v11 逻辑。

载具沿用原分类和名称来源，不增加游戏内写入。原程序将物资、投掷物和车辆放在相关列表中；本版本在读取位置前筛选原 metadata `+0x15` 车辆标识，并排除投掷物源记录。关闭“附近载具”时不读取该列表内的车辆位置；“附近敌人”开关不影响载具。原来的物资分类启用、分类距离、持枪隐藏、油量／血量设置不影响新的载具名称／距离显示。

## 实现依据

原输入 SHA-256 由现有构建脚本固定。只读反汇编在 Actions [39151237812](https://github.com/zwthys-cyber/Core-21A327-TrollStore/actions/runs/39151237812) 和 [39151360995](https://github.com/zwthys-cyber/Core-21A327-TrollStore/actions/runs/39151360995) 执行。

- `D6F30..D6F34` 将 metadata 的 `+0x15` 位复制为源记录的车辆属性；原油量／血量分支还使用同一属性。`D9948..D9950` 将其写入最终缓存记录 `+0x4d`。
- 源记录位于上下文 `+0x3d8/+0x3e0`，步长 32；采集结果位于 `+0x408/+0x410`，步长 88。位置、距离、屏幕有效标志分别为最终记录 `+0x20`、`+0x38`、`+0x50`。
- 新的前置筛选位于 `D959C..D95BC`；范围检查复用被旁路的可选油量读取区域，不更改函数序言、尾声、指针认证或栈帧。通过后继续原缓存追加函数。
- 绘制复用原共享列表循环、名称生命周期、`snprintf` 及描边文字函数；再次检查车辆属性、非投掷物、屏幕有效标志和有限距离。名称文字和距离来自原元数据，不根据猜测的游戏地址添加车型。
- 新开关复用原已持久化的布尔槽 `+0x22`，并与相邻 `+0x23` 的“附近敌人”分别设置原 dirty 标志。旧骨骼渲染已统一使用敌人开关。菜单仍只匹配一次 BeginChild/EndChild。

新增功能仅在 `--model-render --nearby-vehicles` 构建启用；不带新参数的 v19/v11 构建结果和功能配置仍走原路径。打包器和最终载荷验证器均记录、校验具体修改清单及 `CoreNearbyVehiclesVersion=1`；版本为 `CoreModelRenderVersion=12`、Bundle build `40`。

## 验证与边界

编译和全部自动化检查仅在 GitHub Actions 执行。新增 ARM64 回归直接执行实际菜单、原采集循环、筛选、范围和绘制循环，以合成目标和系统调用桩检查：两个开关独立保存；载具在敌人开关关闭时仍可用；普通物资／投掷物排除；旧偏好不干扰；600 米包含、超界／负数／NaN／无穷排除；字体、颜色、原清理流程保留。已有的人物填色运行时、ASan/UBSan、全精度栅格、载荷及签名检查继续执行。

车辆实机显示仍待用户确认。600 米是筛选上限，不能保证原程序能采集所有地图车辆。此前 v19 已有的远距敌人漏显根因仍未确定，本改动不宣称修复该问题；v11 的填色残余闪烁／错位及查询预算限制也未由本次载具功能解决。
