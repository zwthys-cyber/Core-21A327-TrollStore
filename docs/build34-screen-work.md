## build 35 改动

1. 失败时保存实际资源名称和身份、LOD、顶点/权重步长、分区数、索引宽度、前缀实际字节数及具体原因；layout 细分为顶点、权重、分区缺失/超限或索引前缀不完整。最多 16 组不同证据，重复失败不追加，超过上限明确标记截断。样本只包含描述字段，不保存原始网格字节。
2. 样本以不可变快照发布，状态写入不获取绘制锁。即使绘制忙，也能读取已发布失败证据；不为输出诊断额外扫描游戏对象。
3. 同一资源在同一帧只根据已读取状态确定一次可见性和 LOD，后续未选中的描述直接跳过。LOD 变化下一帧重新判断，自动 LOD0 仍明确标为未验证。
4. 完成当前顶点投影后，只有空网格或全部投影顶点处于视口同一半平面之外才跳过栅格；使用实际本帧顶点，不用参考姿态边界或距离猜测。跨屏幕边缘的网格、顶点都在外面但三角形横跨屏幕的情况继续绘制。
5. 新增空/屏幕外网格及未选中 LOD 描述跳过计数。此版本 `projected_mesh_frames` 计通过屏幕检查的网格，与 `empty_or_offscreen_meshes_skipped` 相加可与旧版投影成功网格口径对照，不能直接把该计数下降当作部件丢失。
