# Core 1.6 · v18 · 减少射线拥挤测试版

适用于现有 iPhone16,2 / D84AP、iOS 17.0（21A327）和 TrollStore。版本为 1.6 / build 19 / patch 18，主安装包为 `Core-17.0-21A327-TrollStore-v18-300m.ipa`。

## 显示变化

每帧最多显示 3 条射线，只连接距离不超过 100 米的屏幕内敌人，按原目标处理顺序选取，不承诺距离排序。射线保留 1 个绘制单位的宽度，白色透明度从近处的 255 降至 160，减轻多人聚集时的线条遮挡。

超过数量或射线距离限制的目标继续显示原标记：姓名、方框、距离、红白骨骼，以及屏幕外黄色方向提示仍使用 300 米范围。顶部红色敌人总数沿用原统计，不受射线数量影响。真人红名、人机白名，不附加身份文字。

## 实现与核验

仅在原射线入口增加本帧数量和距离检查；原敌我、距离及投影判断仍先执行。没有增加游戏数据采集或读取。数量放在绘制函数新增的 16 字节私有栈空间中，每帧在原敌人计数器初始化之前清零；跳过射线后继续执行原方框等绘制。原帧指针、保存寄存器、栈保护和指针认证流程保留，公共返回处释放额外空间。

回归执行原绘制函数入口、射线与方框路径及返回，检查多人情况下只有 3 条线、远处目标不占额度、所有方框继续绘制、空帧清零、下一帧恢复额度、原栈保护和保存寄存器正确恢复；另检查开关、距离边界、负数、NaN、无穷及原敌人计数。GitHub 云端完整 35 项 Python 回归、原生并发启动、Mach 转发、日志轮换、缓存传输和子进程清理检查全部通过；最终包载荷与签名在 GitHub macOS 核验通过。服务器不再进行编译或回归，只核对下载包的版本和摘要。实机画面效果仍待确认。

## 安装与日志

用 TrollStore 覆盖安装主 IPA，完全退出 Core 后重新打开，沿用环境准备、初始化和获取信息流程，开启“附近敌人”。日志检查点为 `patch=18`，profile 为 `enemy-markers-300m-low-clutter`。

此版本只改善显示拥挤，不提供防封或反作弊绕过能力，也不能保证使用安全。
