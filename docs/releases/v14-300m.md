# Core 1.6 · v14 · 画面可读性升级测试版

适用于现有 iPhone16,2 / D84AP、iOS 17.0（21A327）和 TrollStore。版本为 1.6 / build 15 / patch 14，主安装包为 `Core-17.0-21A327-TrollStore-v14-300m.ipa`。

## 体验调整

- 名字由 11 增至 14 个绘制单位，再乘原屏幕缩放系数。保持白色、方框上方居中，调用原文字描边接口增加黑色轮廓，方便在天空或浅色建筑前辨认。
- 射线从屏幕底部中央、距底边 10 个绘制单位处引出，减少顶部罗盘附近的线条交叉。100 米内保持不透明白色；100 米以外至 300 米使用白色、透明度 0x70（约 44%）。方框、距离、名字及红白骨骼不随射线变淡。
- `Core-remote-bootstrap.log` 正常写入时限制为 2 MiB，达到限制前把最近尾部保存为 `.log.1`，只保留一份最多 2 MiB 的备份。已有大日志也只复制最近 2 MiB，再写入新日志。争用时跳过本次诊断，不等待文件锁；备份失败时保留已有日志，不影响原调用。

“附近敌人”统一控制名字、方框、射线、距离和红白骨骼，范围继续为 300 米。原姓名读取、短/长字符串复制、空名字提示及清理流程保留；文字描边复用原距离文字所用接口和相同字体。原红白骨骼采集、遮挡判断和就绪条件保留。

## 验证

ARM64 合成回归执行姓名桥接和原描边包装器，覆盖开关、两类目标、英文、中文、长名字及空名，检查 UTF-8 字节边界、14 单位字号、黑色描边参数、字符串清理及后续坐标恢复。射线回归覆盖两种屏幕尺寸、100 米边界和远距离，核验底部起点、透明度及原方框。原 300 米边界、骨骼采集/遮挡、菜单和打包检查继续执行。

macOS 运行时检查扩展了日志轮换、旧日志尾部保留、并发记录完整性、文件锁争用和备份失败，并继续核验真实 Mach 消息、返回码及 errno。启动并发、缓存传输、子进程清理和安装包签名检查继续执行。

本机和 GitHub 的 31 项 Python 回归通过，适配库和新增日志运行时检查通过 iOS SDK 编译检查。GitHub macOS 全部步骤成功，下载后的完整安装包通过载荷和签名核验。v14 实机画面仍待确认；测试不运行手机上的游戏，后续 launchd 接收超时仍未解决。

## 安装与日志

用 TrollStore 覆盖安装主 IPA，完全退出 Core 后重新打开。现有“Core 环境准备”可以继续使用；沿用准备环境、内核初始化、获取信息和开启“附近敌人”的步骤。

新日志检查点为 `patch=14`。运行日志为 `Core-21A327-adaptation.log`、`Core-remote-bootstrap.log`、`Core-remote-bootstrap.log.1` 和 `core-offline-original-id.log`。轮换只作用于远程诊断日志，不删除其余日志。尾部备份的第一行可能是不完整记录；排查时同时保留当前日志和备份。
