# Core 1.6 · v8 · TrollStore 发布版

适用于本次验证的 iPhone16,2 / D84AP，iOS 17.0（21A327）。Core 版本为 1.6，build 9，patch 8。其他设备和系统版本未做实机验证。

此次发布使用原 v8 IPA，SHA-256 与用户已安装并验证的文件相同，不重新编译或修改应用行为。编译来源为提交 `7ae35dd4238651cb3845d2ac43a1c2e92dee290a`，对应 [GitHub Actions 构建](https://github.com/zwthys-cyber/Core-21A327-TrollStore/actions/runs/38069024526)。

## 已验证的功能

- 环境适配通过，原 pe-v1 内核后端初始化成功。
- SpringBoard 远程初始化成功，三个悬浮窗口已注册到系统宿主。
- 用户确认界面显示“获取成功”，悬浮菜单可以操作。
- 原缓存发布器及摘要校验继续执行，未强制修改内核或窗口状态为成功。

## 安装

1. 用 TrollStore 安装 `Core-17.0-21A327-TrollStore-v8.ipa` 和 `Core-Cache-Prepare-TrollStore.ipa`。已安装并正常使用的 v8 和准备工具可以继续保留。
2. 在手机完整重启后，先打开“Core 环境准备”，点击“准备 Core 环境”，确认成功。
3. 再打开 Core，等待环境就绪，点击一次内核利用，等待悬浮注册状态稳定。
4. 确认悬浮菜单可操作后，再测试获取信息。准备和本次初始化之间不要再次重启手机。
5. 若出现失败，导出 Core 中的 `Core-21A327-adaptation.log`、`core-offline-original-id.log` 和 `Core-remote-bootstrap.log`，按进程起始记录区分历史运行。

## 当前限制

- 用户随后反馈游戏账号被封 7 天；现有 Core 设备日志不能确定具体检测项。这里的功能可用验证不代表游戏使用安全，也不承诺避免封禁。
- 后续 launchd 初始化仍存在接收超时；已验证运行的最终状态为 `hosted=1`，同时存在 `quarantine=1`。本次主要功能可用，不代表整个远程初始化流程或每次重新运行都已验证稳定。
- 保留 v8 的远程调用诊断记录，发布包仍会生成相应日志。
- 本地授权组件的自动校验入口已停用，授权后台请求在当前日志中被取消。界面中的 `2099-12-31 23:59:59` 为本地固定显示值。服务器上的真实有效期和设备绑定没有延长或修改；服务器卡密到期后的实机使用尚未验证，不承诺永久可用或所有服务端功能可用。
