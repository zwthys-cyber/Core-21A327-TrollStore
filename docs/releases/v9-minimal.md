# Core 1.6 · v9 Minimal · TrollStore

目标设备：已提供的 iPhone16,2 / D84AP，iOS 17.0（21A327）。版本为 1.6 / build 10 / patch 9，功能配置为 `position-distance-only`。这是基于原 Core 的精简版，没有完整重写原数据读取和悬浮宿主。

## 范围

- 悬浮菜单仅保留初始化页和位置页；位置页仅有“位置距离”开关。
- 使用原敌人筛选、投影坐标和距离文字，统一控制原人类玩家及人机类别。关闭名称、血条、方框、射线、骨骼、武器、雷达、物资、轨迹、预警、人数、辅助圈等显示。
- 停用原自瞄和压枪输入处理函数，从入口直接返回。其余显示开关在原执行处固定关闭，已有配置不会重新激活这些路径。
- 去掉掩体判断、运行模式、主题、颜色、FPS、性能监测等菜单。保留环境准备、原内核初始化、获取信息、数据读取与悬浮注册依赖。
- 所有修改在打包前静态实施，按原程序 SHA-256 和逐条指令核对；未使用的原函数仍保存在二进制内，未声称物理删除全部原代码。

## 验证范围

21 项 Python 检查覆盖原输入身份、允许修改范围、原缓存与内核代码保留，以及 ARM64 指令执行检查：输入处理函数不读写数据直接返回；旧菜单索引只能进入初始化/位置页；旧配置全开仍无法启用其他绘制；位置页只有一个开关、BeginChild/EndChild 成对、配置改变仍设置原保存标记。

GitHub macOS 构建继续执行方法发布并发、真实 Mach 消息转发、准备缓存接收、独立子进程清理测试和两个 IPA 的完整签名、权限、依赖、资源及非签名载荷核验。ARM64 测试使用合成配置与 UI 桩，没有在手机或游戏中运行。最终构建状态及摘要以附带编译元数据和 SHA256SUMS.txt 为准。

v8 曾通过本次设备的主要功能验证，用户随后反馈游戏封禁 7 天。现有 Core 日志不能确定具体封禁原因。v9 尚未进行实机验证，减少功能或重新编写均不能保证防封。保留的敌人信息读取仍可能触发游戏规则；本版本不提供检测隐藏或封禁规避实现。

## 安装

用 TrollStore 覆盖安装 `Core-17.0-21A327-TrollStore-v9-Minimal.ipa`。已安装的“Core 环境准备”可继续使用。原环境准备和初始化流程不变；手机重启后需要按当前启动重新准备缓存。悬浮页只显示“初始化”和“位置”，位置页的“位置距离”开关控制原投影位置的距离文字。

已知后续 launchd 初始化接收超时尚未修复；系统隔离状态和原成功校验不变。保留原运行诊断日志。本次不新增或修改授权组件行为，服务器真实有效期与绑定状态未更改。
