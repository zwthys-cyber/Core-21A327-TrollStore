# Core 1.6 · v19 · 0fe975f 基础 / 600 米测试版

适用于现有 iPhone16,2 / D84AP、iOS 17.0（21A327）和 TrollStore。版本为 1.6 / build 20 / patch 19，主安装包为 `Core-17.0-21A327-TrollStore-v19-600m.ipa`，同时包含屏幕上方射线起点调整。

## 显示行为

按用户要求，以 `0fe975fc6053a0af8cac90c4a860696d08dec8c2` 为显示逻辑基准，将总距离上限从 300 米提高到 600 米，覆盖屏幕内姓名、方框、射线、距离、骨骼，以及屏幕外方向提示和顶部敌人总数。真人姓名红色，人机姓名白色，不显示身份文字；空名字仍显示“未知玩家”。

射线起点按本次补充要求改为屏幕上方中央，向下连接目标；采用原顶部坐标，位于顶部下方 10 个绘制单位。射线数量和透明度沿用该提交：没有新增的每帧 3 条限制，100 米内为不透明白色，100 至 600 米为透明度 112 的白色，线宽为 1 个绘制单位，起点为屏幕上方中央。方框、红白骨骼、姓名描边、黄色方向箭头和顶部红色数字沿用该提交。

600 米只改变原显示及骨骼采集的距离条件，实际目标必须由游戏加载并被原采集流程获取，不保证获取游戏中未提供的目标数据。

## 实现与核验

与指定提交的主程序显示补丁比较，只修改总距离浮点指令、骨骼采集和绘制范围两个整数指令、等长“600米标记”文字，并恢复原顶部射线坐标指令及移除底部坐标桥接。原绘制栈大小、敌人计数清零、射线数量入口及原雷达区域恢复为指定提交的行为。授权及环境适配、远程转发、日志轮换和其他保留功能以该提交为基础，版本与 profile 更新用于识别本次构建。

GitHub 检查会独立载入指定历史提交的补丁并逐字节对比，仅允许上述距离、文字和顶部射线坐标位置发生主程序变化。距离回归覆盖原 300 米以上目标、450 米、600 米边界、600.01 米拒绝，以及不同屏幕尺寸下的顶部中央射线起点、姓名颜色、计数、屏幕外提示和骨骼路径。全部编译和自动化回归只在 GitHub Actions 执行，服务器只修改文件、查看 CI、下载发布产物及轻量核对版本和摘要。

GitHub 云端完整 35 项 Python 回归通过，包含指定历史提交的逐字节对照、600 米边界和顶部射线起点检查。macOS 原生并发启动、Mach 转发、日志轮换、缓存传输和子进程清理检查全部通过，最终包完整载荷与签名在云端核验成功。服务器仅核对下载包的版本和摘要。600 米实机显示及负载仍待确认。
