# Core 1.6 · v15 · 屏幕外方向提示测试版

适用于现有 iPhone16,2 / D84AP、iOS 17.0（21A327）和 TrollStore。版本为 1.6 / build 16 / patch 15，主安装包为 `Core-17.0-21A327-TrollStore-v15-300m.ipa`。

## 显示变化

此前精简版关闭了原屏幕外提示，目标离开正面视野后没有方向标记。v15 将屏幕外箭头和距离接入原“附近敌人”开关。目标在 300 米内、通过原敌我及距离检查、原投影标记为屏幕外时，显示黄色箭头、黑色轮廓和带描边的距离文字。屏幕内继续使用 v14 的名字、方框、射线、距离和红白骨骼。

方向使用原本已缓存的人物世界 X/Y 与当前摄像机朝向计算水平角度。左右目标分别朝左右，正后方目标朝下，转动视角时重新按当前朝向计算。它不依赖背后目标可能反转或无效的投影坐标；不表示高度差。水平方向无法确定、位置或朝向非有限数、屏幕尺寸无效时跳过箭头。

复用原屏幕边缘放置、七点箭头填充及黑色轮廓、距离描边和循环清理。箭头固定原样式 0、40 个绘制单位；当前屏幕尺寸和缩放来自绘制上下文。原敌我判断、有限距离检查和 300 米边界先于箭头路径；队友及超限目标不显示。

用于方向计算的短指令块放在已禁用的雷达数学区域；雷达开关仍被固定为关闭。保存边缘放置所需的浮点输入后再调用原 libc 数学接口，恢复后交给原放置逻辑。除显示流程外，不修改采集、内核、输入或远程启动路径。

## 核验

新增 ARM64 合成检查覆盖 128 组配置：前后左右、四个斜向、旋转及负数/整圈朝向、两种屏幕尺寸、两类目标和开关。执行原敌我/距离筛选、边缘放置、原箭头七点生成及原距离描边包装器，核验箭头尖端位置和朝向、填充/轮廓一致、文字和所有顶点在屏幕内、距离及循环状态。

额外配置覆盖 300 米边界、超限、负数、NaN、无穷、队友、屏幕内目标、水平方向为零以及无效位置/朝向/尺寸。故意提供无效投影坐标，并模拟 libc 破坏调用者保存的浮点寄存器，检查方向及边缘输入不会依赖这些数据。外部图形、字体、字符串和 libc 数学使用合成桩，不运行手机上的游戏。

本机完整 32 项 Python 回归通过，适配库及日志检查通过 iOS SDK 编译。GitHub 原 macOS 并发启动、真实 Mach 转发、日志轮换、缓存传输、子进程清理和最终包核验继续执行，结果待填入。v15 实机箭头效果仍待确认；原后续 launchd 接收超时仍未解决。

## 安装与日志

用 TrollStore 覆盖安装主 IPA，完全退出 Core 后重开。已有“Core 环境准备”可以继续使用，沿用准备、初始化、获取信息的流程，再开启“附近敌人”。同一个开关控制正面标记与屏幕外提示。

日志检查点为 `patch=15`，profile 为 `enemy-markers-300m-direction`。原三类日志与远程日志尾部备份继续使用，远程日志正常写入时每份最多 2 MiB、只保留一份备份。不把人物位置、姓名或摄像机朝向写入日志。
