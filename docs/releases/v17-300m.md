# Core 1.6 · v17 · 真人红名／人机白名测试版

适用于现有 iPhone16,2 / D84AP、iOS 17.0（21A327）和 TrollStore。版本为 1.6 / build 18 / patch 17，主安装包为 `Core-17.0-21A327-TrollStore-v17-300m.ipa`。

## 显示变化

真人姓名显示不透明红色，人机姓名显示不透明白色，两类都有原黑色描边。不显示“【真人】”“【人机】”分类文字，只用颜色区分。颜色读取原缓存人机标志，零值为真人，非零值为人机，不根据名字猜测。空名字统一使用“未知玩家”提示。

姓名仍按原字体、宽度测量和居中流程显示，字号为 14 个绘制单位乘当前缩放。300 米范围、顶部红色敌人总数、方框、射线、距离、红白骨骼和屏幕外黄色方向提示沿用 v16。

## 实现与核验

姓名颜色入口跳转到已被绕过的原血条显示区域，在同一绘制栈帧内选择 packed ABGR 颜色：真人 `0xff0000ff`，人机 `0xffffffff`，再返回原姓名参数准备流程。只占用 28 字节，没有新的函数调用、栈操作或字符串分配。原姓名查询、副本复制、宽度测量、黑色描边和释放流程保留；不改写原姓名缓存。移除 v16 的标签追加桥接、入口和文字修改；空名字选择原“未知玩家”字符串。屏幕外方向提示的原入口保留。

姓名回归执行实际修改后的 ARM64 姓名路径，覆盖两类身份、非零人机标志、开关、英文/中文、长/空名字及短长字符串边界，检查最终绘制颜色、不追加分类文字、空名字中性提示、黑色描边、居中位置、原缓存不变、释放与后续坐标恢复。本机和 GitHub 完整 34 项 Python 回归通过，适配库通过 iOS SDK 编译。GitHub macOS 并发启动、真实 Mach 转发、日志轮换、缓存传输、子进程清理和最终包核验全部成功。下载产物再次通过完整载荷与签名检查。实机颜色效果仍待确认。
