## 蒙皮计算和离线预览

`patch/CoreModelSkinning.h` 提供参考骨骼层级累乘、逆绑定矩阵、当前姿态及组件世界变换、分区骨骼表和四权重蒙皮。通用库在 -1 映射涉及有权重骨骼时返回未知，不去掉该权重并重新归一化。边界检查涵盖 224 字节分区、索引/顶点范围、骨骼槽位、非有限变换、奇异逆矩阵及严格权重和。实时绘制现已使用此库；实时层另显式提供标准 Master Pose 的参考姿态回退，并记录次数及游戏特定行为尚未验证的状态。

`scripts/model_mesh_preview.mjs` 及 HTML 模板使用实际报告建立模型，支持参考姿态/采集姿态重建、六帧切换、LOD 选择、附件开关、旋转/缩放、三角形边及图片导出。跨帧按目录 ID 查找缓冲，再用当前帧资源索引查参考骨骼，不能把首次采集的资源索引用到后续换装帧。附件主组件可递归解析，检查完整 FName、循环和组件世界变换；未知姿态顶点及相关三角形不显示。姿态重建仍假设独立 `0x848` 为组件空间动画输入，原子采样和最终引擎形变没有被证明。
