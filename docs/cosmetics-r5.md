# Core 分类外观试穿 r5

r5 在“位置”下面的“美化”栏目加入 143 个外观候选：外套 60、头发 53、裤子 14、鞋子 5、
降落伞 11。名称与 ID 已同固定版本的文本目录和所提供包内 Item 名称表交叉核对。
金龙外套已有用户画面确认，新增项目仍需逐项确认，不能将候选数量当作实机通过数量。

## 操作

1. 巨魔覆盖安装 `Core-17.0-21A327-cosmetics-catalog-r5.ipa`。
2. 穿戴对应部位的普通物品，进入训练场，完成 Core 初始化和原有游戏采集。
3. 悬浮菜单点“位置”下面的“美化”，用“换分类”“上一页”“下一页”选择候选。
4. 勾选一项试穿约 15 秒，取消勾选可提前恢复；选择其他项目会先恢复上一项。

每次记录该部位原来穿戴的 ID，恢复原物品，不再限定必须穿初始白 T 恤。
若绑定、角色、物品实例或游戏自行更新的数据不再匹配，停止写入并在报告中记录原因。
恢复尚未确认时，保留恢复记录并阻止继续覆盖。

报告自动保存在 `Documents/Core-cosmetics-probe.json`，可从“文件 → 我的 iPhone → Core”读取。
报告包括项目、部位、原 ID、目标 ID、写入、观测和恢复结果。武器候选仅作只读采样。
为继续适配头盔、背包和枪械，可在训练场穿戴头盔、背包且手持枪后试穿一次，再提供报告。

枪械、头盔、背包、大厅以及包内自定义模型、材质、特效尚未接入；本版不是整包转换完成版。
仅通过修改现有外观 ID，不能说明已复现 PAK 内所有资源修改。
