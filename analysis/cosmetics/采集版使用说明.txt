Core 远程 GameThread 入队试换 r30
适用：iOS 17.0 / 21A327、巨魔、和平精英 1.38.12（15915）。

r29 实机：getpid 已对齐（pid_matches_published=true），但 game_thread_probe 报
core-session-not-ready——探测仍要求 snapshot.words[1]，而 r26 打开路径只发布
C53460/BD4C5C/C534B0。r30 改为与 getpid 相同的已发布会话门闩。

大厅不需要宾利。进训练场坐上任意车后再开会话。

使用方法：
1. 巨魔覆盖安装 Core-17.0-21A327-cosmetics-vehicle-r30.ipa。
2. 游戏前台 → 划掉 Core 再开 →「内核利用」（不要「获取信息」）。
3. 进训练场坐上任意载具。
4. 切回游戏前台，再让 Core 进后台打开会话。
5. 导出 Core-cosmetics-probe.json。

关注：
- game_thread_probe.session_source：应为 published-globals 或 snapshot
- taskgraph_present / vehicle_resolve / enqueue_status
- vehicle_resolve=no-current-vehicle：还没坐上车
- enqueue_status=create-and-dispatch-returned：入队返回（≠已换肤）
- mprotect-failed：RX 被拒

vehicle_appearance_changes_implemented 仍为 false，直到画面确认。
所有编译与二进制分析均在 GitHub Actions 执行。
