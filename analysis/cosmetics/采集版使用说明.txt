Core 美化车辆换肤 — r39

【在维护者宣布成品 IPA 之前】
不要安装中间构建，不要做实机试验。本文件只说明成品菜单用法，不是测试工单。

用法（成品路径）：
1. 用 Core 完成「内核利用」，再进入游戏并坐上当前载具（训练场即可；大厅无车则不可换）。
2. 打开美化菜单 →「车辆适配」
3. 按「原车 → 目标车皮」选择配料。菜单共 35 个包内映射、每页 4 项；只允许当前原车 item ID 完全匹配的配料。
4. 取消已选项即可恢复原车。切换目标时会先恢复当前改动，再应用新目标。

不会自动入队：会话打开 / 进程探测只做只读诊断。

车辆状态使用 item ID；PutOn 使用目录中独立记录的 resource ID。目录来自包内
game_patch_1.38.12.16050.pak 与 16052.pak 的 Item 行名交换，并由 Actions 重新生成核对。
