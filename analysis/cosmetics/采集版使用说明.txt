Core 美化适配写入检测版 r2
适用：iOS 17.0 / 21A327、巨魔安装、和平精英 1.38.12（15915）。

当前功能是检查内核写入接口并采集角色外观数据；尚未启用换装。
检测只向上次确认的初始套装字段写回相同 ID，数值和外观保持原样。
原程序的目标进程、会话、映射、预期值和回读检查全部保留。
包内没有附带或替换游戏 PAK 文件。

1. 用巨魔安装 Core-17.0-21A327-cosmetics-probe-r2.ipa。
   与原 Core 使用相同应用标识，作为更新安装；不需要删除原应用。
2. 保持上次采集时的初始套装，打开和平精英并进入训练场。
3. 返回 Core，完成原有初始化，启用原有游戏采集功能。
4. 点右下角“美化适配”→“检测写入并采集”，立即切回训练场。
5. 等约 24 秒，返回 Core，点“美化适配”→“导出报告”。
6. 将 Core-cosmetics-probe.json 发回。
   write_check 中的状态用于确认当前 Core 会话是否具备实际写入能力。

若没有成功采集，也请保留报告中的状态，便于定位原因。
报告也会保存在 Core 的 Documents/Core-cosmetics-probe.json，
可通过文件共享取出；它不含内存地址、进程号或物品实例编号。

IPA 的编译、自动化测试与签名验证全部在 GitHub Actions 执行。
真机运行和实际换装效果尚需手机验证。
