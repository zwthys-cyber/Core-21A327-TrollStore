Core 远程 GameThread 诊断 r31（已停用入队）
适用：iOS 17.0 / 21A327、巨魔、和平精英 1.38.12（15915）。

紧急：r30 在 getpid 对齐后会安装 RX 跳板并 CreateAndDispatch / PutOn，
实机出现游戏卡死、无法移动画面。r31 已完全禁用该入队路径，只保留只读诊断。

请先强制划掉游戏与 Core，再覆盖安装 r31。不要继续使用 r28–r30 做换肤入队。

r31 仍会：
- 打开游戏远程会话并 getpid 核对
- 调用 IsSafeForGameThread / FTaskGraphInterface::Get（只读）
- 解析当前载具 Avatar（需训练场坐上车才有）
不会再 calloc / mprotect / CreateAndDispatch / PutOn。

导出 JSON 关注：
- session_source、taskgraph_present、vehicle_resolve
- enqueue_status 应为 disabled-after-device-freeze

vehicle_appearance_changes_implemented=false。换肤未完成。
所有编译与二进制分析均在 GitHub Actions 执行。
