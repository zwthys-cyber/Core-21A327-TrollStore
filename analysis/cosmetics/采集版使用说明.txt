用法（成品路径）：
1. 用 Core 完成「内核利用」，再进入游戏并坐上任意当前载具（训练场即可；大厅无车则不可换）。
2. 打开美化菜单 →「车辆适配」
3. 点「装目标车皮」→ PutOn 3349002（宾利欧陆GT敞篷火焰橘），分离 RX 代码页 / RW 数据页入队
4. 点「恢复原车」→ 对捕获的原皮肤 ID 再入队 PutOn

不会自动入队：会话打开 / 进程探测只做只读诊断。
